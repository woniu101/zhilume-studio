# Zhilume Studio

织镜创作画布。React + TypeScript + React Flow + Tiptap，共用 Web 和 Electron 界面。当前为 **0.8.0 初版开发**，本轮配套 Server 0.6.0 / Worker 0.5.0。需要调整时直接重构，不保留历史开发版兼容层。

## 图片生成与编辑

单击空图片节点，直接在节点下方展开编辑区；已有图片或文本节点也可点击顶部 **生成**。提示词可从当前/上游文本节点带入，参考图可从当前/上游图片带入、添加、移除和排序。

- Qwen Image 2512：文生图；Qwen Image 2.1：文生图、指令编辑、多图参考及 RGBA PNG。
- 切换操作、模型和配置保留输入；不支持的参数明确提示并禁用提交，不静默删除参考图。
- 编辑输出比例由第一张参考图确定，参考分辨率来自 Worker 配置。只有文生图指定宽高。
- 无在线图片配置时仍可编辑当前表单；生成参数、文本草稿与待重试请求随项目自动保存，重开后恢复；断线沿用本机草稿和冲突处理。当前显示 GPU 待验收，需 Worker 显式启用后才能试运行。
- 参考图可直接上传、从素材库拖入或选择并排序；添加参考图自动切到 Qwen 2.1 编辑/多参考。参考上传保留在项目素材库，不创建额外画布节点。
- 文生图提供 1:1、16:9、9:16、4:3、3:4 与自定义尺寸，预设按执行配置上限过滤并保持 32 像素对齐。
- 节点直接显示排队、执行、失败原因，并提供重试和取消。
- 请求幂等，提交失败可重试；生成结果作为新节点回到画布，原素材和来源参数保留。
- 本轮完成本地假 ComfyUI 联调和浏览器交互验证，**没有进行真实 GPU 推理验收**。

文本空节点单击可直接输入并保存；视频和音频空节点提供素材入口，生成能力尚未接入。没有积分系统。

## 当前媒体工具

选择有素材的图片/视频节点，点击顶部 **工具**。

- 原图裁剪：拖动框选或精确像素坐标；宫格切分最多 8 × 8，无遗漏边缘像素。
- 拼图：最多 16 张，排序、列数、间距、背景、单格尺寸；图片保持完整比例。单图/输出不超过 3200 万像素、拼图原图合计不超过 6400 万像素。
- 视频：本机 FFmpeg 子进程、浏览器按需加载的 ffmpeg.wasm，或在线 CPU Worker；截取输出 MP4 H.264/AAC，抽音轨输出 PCM WAV。
- 浏览器保守限制输入 64 MB / 原片 120 秒 / 单次执行 180 秒。超出可选择 CPU Worker 或桌面版。这不是已完成上限压力验证的承诺。
- 先处理、预览/下载，再保存为新节点；同类型单结果可替换当前节点。原资产不改写，可撤销画布操作。
- 上传失败保留本窗口结果，可重试或下载；关闭窗口不承诺恢复未保存的 Blob。分批上传重试不会重复上传已经成功的结果。
- 结果携带来源资产和操作参数；真实 CPU 任务与模拟任务分开显示。

四类节点、原比例媒体预览、波形播放、外置动效连接点、替换、命名、系统剪贴板、富文本、草稿恢复、素材信息等已有能力继续保留。

## 启动

先启动 Zhilume Server，再执行：

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`。Server 地址留空时使用 Vite 的本机 4310 代理，访问凭证从 Server 启动器复制，或读取开发 Server 的 `.data/admin-token`。

```powershell
npm run build
npm run pack
```

Web 产物在 `dist/`。可由静态站点服务，`/api` 反向代理到 Server；也可在连接页填写 Server 完整地址，并在 Server 的 `ZHILUME_ORIGINS` 添加 Web 站点来源。

Windows 目录包在 `release/win-unpacked/`，入口 `Zhilume Studio.exe`。需要完整目录，不能只复制 EXE。`npm run desktop` 运行本地构建。若安装时关闭生命周期脚本，先执行 `node node_modules/electron/install.js`。

## 已实现的交互

- 创建、搜索、重命名、归档与恢复项目。
- 文本、图片、视频、音频节点；文本编辑，自定义视频/音频播放器、真实波形进度和图片预览。
- 拖动、框选、平移、缩放、连线、复制粘贴、分组/解组、删除、撤销重做。
- 自动保存、浏览器本地草稿、版本冲突提示、画布 JSON 导出。
- 上传素材、项目素材库、文件夹创建/改名/移动/移除、搜索、改名、说明、移动素材、复用与下载。
- 模拟任务提交、取消、重试，结果以新节点追加，保留输入。
- 中性黑白灰＋少量雾蓝，深色 / 浅色 / 跟随系统。

| 操作 | 交互 |
|---|---|
| 平移画布 | 空格＋拖动，或手形工具；滚轮平移 |
| 缩放 | Ctrl＋滚轮，或底部缩放按钮 |
| 插入素材 | 文件拖入；素材库拖入或双击 |
| 空节点编辑 | 单击展开，点击外部或 Esc 收起；随项目自动保存草稿 |
| 编辑 / 预览 | 双击节点；选中后浮动工具栏 |
| 拖动音视频 | 按住视频画面或音频波形移动；单击波形定位，播放/进度等控件独立 |
| 复制粘贴 | Ctrl+C / Ctrl+V（当前画布应用内） |
| 分组 / 取消分组 | Ctrl+G / Ctrl+Shift+G |
| 替换媒体 | 悬停/选中节点 → 替换；电脑或项目素材库 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |

连线保存引用关系，**不自动执行整条工作流**。当前支持模拟任务、真实 CPU 媒体处理及可选 Qwen 图片执行链路；GPU 实际推理尚待验收。

浏览器会话凭证仅存本标签页 sessionStorage；桌面会话通过 Electron safeStorage 保存。画布数据只存资产 ID，不保存文件 Base64 或临时签名地址。媒体签名刷新保留有效旧地址，避免状态轮询重置播放器。

## 测试与限制

`npm test` 验证连线环路、分组删除时的坐标恢复、保存文档剔除瞬时状态。`npm run build` 包含 TypeScript 检查。

新增 `npx playwright test`，使用独立 Chrome 测试进程、隔离 `.test-data/playwright` 与 Server 4319，需本机已安装 Chrome、相邻 Server 已构建，5173/4319 未被占用。覆盖视频/音频实际播放与定位、文件替换、视角恢复、100 个文本节点会话过期恢复。测试不使用用户项目。`ZHILUME_DEV_SERVER` 可覆盖 Vite 的后端代理地址。

未完成项包括跨窗口富节点剪贴板、历史版本、100 个混合媒体节点性能基准、原生媒体全操作、断点续传及干净机器安装验收。JSON 导出只含布局与素材引用。大于 64 MiB 或无法解码的音频显示可定位的进度区域，不伪造波形；兼容性仍取决于媒体编码。

协议快照在 `src/contracts/`，由 Server 导出。产品需求和开发状态的版本化副本在 Server 仓库 `docs/`。

## 媒体依赖与验收

`npm ci` 安装 `ffmpeg-static`（当前锁定下载版本 b6.1.1）供桌面使用。`prepare:media` 将单线程 wasm 核心复制到同源 `public/ffmpeg`，Web 部署必须完整保留 `dist/ffmpeg`。运行时不依赖第三方 CDN。

```powershell
npm test
# 配套 Server 构建好后，在三个仓库并列目录下运行：
npx playwright test
```

单元测试包括真正调用捆绑 FFmpeg 的 IPC 处理/取消；浏览器测试包含裁剪、拼图、切分、上传重试、WASM 音轨提取和静音视频截取。原生窗口全操作、各类大文件与上限压力测试仍需独立验收。

FFmpeg 相关分发来源与许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
