# Studio 0.17.0：底部工具栏与专注编辑

类型切换、模型、参数和生成集中到底部；顶部保留模式、历史与展开，取消关闭 X。展开进入铺满窗口的专注编辑；Esc 依次关闭子浮层、还原、收起，草稿保留。离线状态单独提示，主按钮统一“生成”。

同类型生成更新当前节点；重复生成、替换和采用历史都保留原内容。编辑区提交后保持打开，草稿修改不会改变已提交任务。仅空、无连线且没有成功或在途任务的节点允许切换类型。图片转视频／文本转语音先建立明确的输出目标。

提示词优化与执行器细节默认收起。模型菜单和其他选择器统一深浅主题与键盘操作；保存明确的执行规格和高级 Worker 选择，不因离线切换模型。请配套使用 Server 0.13.2。详细数据语义与验收见 Server docs/generation-experience-plan.md。

输出尺寸、更多参数、视频、语音与执行端设置使用独立浮层；参考编辑、提示词建议及历史版本使用较宽面板。打开参数不改变编辑区高度，Esc 从最内层逐级关闭。桌面版输入框支持系统右键编辑菜单，网页保留浏览器默认菜单。表单焦点描边画在控件内部，避免被滚动容器裁切。

四类节点共享模式、正文、辅助操作、状态和底部操作区。只有正文滚动；优化提示词和字数同排，Worker 选择收进参数。文本正文编辑草稿与生成要求分别保存；未保存正文可明确放弃。工具栏保留同类型操作，跨类型生成及整理操作进入“更多”。小窗口自动避让节点工具栏。

视频参考按图片、视频、音频分类添加，卡片直接显示预览、试听、编号标签和移除；音色卡片直接显示片段，替换与详细调整放在浮层。正文滚动与表单禁用区域分离，短窗口不允许提示词覆盖操作栏。视频主界面采用中文模式，保留实际时长与像素尺寸。

# Zhilume Studio

织镜创作画布。React + TypeScript + React Flow + Tiptap，共用 Web 和 Electron 界面。当前为 **0.17.0 初版开发**，本轮配套 Server 0.13.2；Worker 本轮未修改。需要调整时直接重构，不保留历史开发版兼容层。

最新 EXE 固定为 `release/win-unpacked/Zhilume Studio.exe`，执行 `npm run pack` 直接更新该目录；应用数据保留在用户数据目录。

## 图片生成与编辑

单击图片节点（空白或已有素材）展开节点外部编辑区；文本节点可在编辑区切换 **编辑正文 / 生成文本**。编辑区使用固定屏幕尺寸，可展开到画布中央；点击外部收起，Esc 先关闭内部参数或预览，再收起编辑区。提示词可从当前/上游文本节点带入，参考图可从当前/上游图片带入、添加、移除和排序。

- Qwen Image 2512：文生图；Qwen Image 2.1：文生图、指令编辑、多图参考及 RGBA PNG。
- 切换操作、模型和配置保留输入；不支持的参数明确提示并禁用提交，不静默删除参考图。
- 编辑输出比例由第一张参考图确定，参考分辨率来自 Worker 配置。只有文生图指定宽高。
- 无在线图片配置时仍可编辑当前表单；生成参数、文本草稿与待重试请求随项目自动保存，重开后恢复；断线沿用本机草稿和冲突处理。当前显示 GPU 待验收，需 Worker 显式启用后才能试运行。
- 参考图可直接上传、从素材库拖入或选择并排序；添加参考图按数量选择编辑/多参考方式；当前模型不支持时保留输入，点击“切换至 Qwen 2.1”再切换模型。参考上传保留在项目素材库，不创建额外画布节点。
- 文生图提供 1:1、16:9、9:16、4:3、3:4、3:2、2:3 与自定义尺寸，预设按执行配置上限过滤并保持 32 像素对齐。
- 参考卡片支持缩略预览、拖动排序和设为构图基准；第一张控制编辑输出比例。新增引用按在线配置上限控制，Qwen 2.1 模型上限 10 张；当前部署配置仍可为 4 张。超限已有引用不静默丢弃，可保存草稿后调整。
- 输出参数面板显示实际像素尺寸和透明背景；更多参数收纳执行配置、反向提示词、步数与种子。没有未接入的积分、提示词优化开关或模型参数。
- 节点直接显示排队、执行、失败原因，并提供重试和取消。
- 请求幂等，提交失败可重试；生成结果更新当前节点，原内容和来源参数保留在历史；另存版本才创建新节点。
- 本轮验证紧凑编辑区和能力约束，没有重新运行 GPU；此前上海二 A Qwen 样本验收见 Server 云端报告。IndexTTS、H3 与用户主动触发的提示词优化已接入。

文本空节点单击可直接输入并保存；空视频、音频节点单击展开 H3 与 IndexTTS 编辑区。没有积分系统。

## 当前媒体工具

选择有素材的图片/视频节点，点击顶部 **工具**。

- 原图裁剪：拖动框选或精确像素坐标；宫格切分最多 8 × 8，无遗漏边缘像素。
- 拼图：最多 16 张，排序、列数、间距、背景、单格尺寸；图片保持完整比例。单图/输出不超过 3200 万像素、拼图原图合计不超过 6400 万像素。
- 视频：Electron 主进程 FFmpeg，Web 提交 Server 单并发队列；截取输出 MP4 H.264/AAC，抽音轨输出 PCM WAV。
- 裁剪预览后默认更新当前节点；视频截取完成后原位采用，均保留历史。拼图、宫格切分与抽音轨创建输出节点，原资产不改写。
- 上传失败保留本窗口结果，可重试或下载；关闭窗口不承诺恢复未保存的 Blob。分批上传重试不会重复上传已经成功的结果。
- 结果携带来源资产和操作参数；真实 CPU 任务与模拟任务分开显示。

四类节点、原比例媒体预览、波形播放、外置动效连接点、替换、命名、系统剪贴板、富文本、草稿恢复、素材信息等已有能力继续保留。

## 启动

先启动 Zhilume Server，再执行：

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`。Server 地址留空时使用 Vite 的本机 4310 代理，访问凭证从 Server 启动器复制，或读取开发 Server 的 `.data/admin-token`。

```powershell
npm run build
npm run pack
```

Web 产物在 `dist/`。可由静态站点服务，`/api` 反向代理到 Server；也可在连接页填写 Server 完整地址，并在 Server 的 `ZHILUME_ORIGINS` 添加 Web 站点来源。

Windows 目录包在 `release/win-unpacked/`，入口 `Zhilume Studio.exe`。需要完整目录，不能只复制 EXE。`npm run desktop` 运行本地构建。若安装时关闭生命周期脚本，先执行 `node node_modules/electron/install.js`。

## 已实现的交互

- 创建、搜索、重命名、归档与恢复项目。
- 文本、图片、视频、音频节点；文本编辑，自定义视频/音频播放器、真实波形进度和图片预览。
- 拖动、框选、平移、缩放、连线、复制粘贴、分组/解组、删除、撤销重做。
- 自动保存、浏览器本地草稿、版本冲突提示、画布 JSON 导出。
- 上传素材、项目素材库、文件夹创建/改名/移动/移除、搜索、改名、说明、移动素材、复用与下载。
- 创作界面仅提供实际生成和媒体处理入口；模拟任务仅用于后端集成验收，任务记录仍明确标注测试结果。
- 中性黑白灰＋少量雾蓝，深色 / 浅色 / 跟随系统。

| 操作 | 交互 |
|---|---|
| 平移画布 | 空格＋拖动，或手形工具；滚轮平移 |
| 缩放 | Ctrl＋滚轮，或底部缩放按钮 |
| 插入素材 | 文件拖入；素材库拖入或双击 |
| 空节点编辑 | 单击展开，点击外部或 Esc 收起；随项目自动保存草稿 |
| 编辑 / 预览 | 双击节点；选中后浮动工具栏 |
| 拖动音视频 | 按住视频画面或音频波形移动；单击波形定位，播放/进度等控件独立 |
| 复制粘贴 | Ctrl+C / Ctrl+V（当前画布应用内） |
| 分组 / 取消分组 | Ctrl+G / Ctrl+Shift+G |
| 替换媒体 | 悬停/选中节点 → 替换；电脑或项目素材库 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |

连线保存引用关系，**不自动执行整条工作流**。当前支持文本、图片、视频、语音生成及真实 CPU 媒体处理；上海二 A GPU 样本实测见 Server 云端验收报告。

浏览器会话凭证仅存本标签页 sessionStorage；桌面会话通过 Electron safeStorage 保存。画布数据只存资产 ID，不保存文件 Base64 或临时签名地址。媒体签名刷新保留有效旧地址，避免状态轮询重置播放器。

## 测试与限制

`npm test` 验证连线环路、分组删除时的坐标恢复、保存文档剔除瞬时状态。`npm run build` 包含 TypeScript 检查。

新增 `npx playwright test`，使用独立 Chrome 测试进程、隔离 `.test-data/playwright` 与 Server 4319，需本机已安装 Chrome、相邻 Server 已构建，5173/4319 未被占用。覆盖视频/音频实际播放与定位、文件替换、视角恢复、100 个文本节点会话过期恢复。测试不使用用户项目。`ZHILUME_DEV_SERVER` 可覆盖 Vite 的后端代理地址。

未完成项包括跨窗口富节点剪贴板、历史版本、100 个混合媒体节点性能基准、原生媒体全操作、断点续传及干净机器安装验收。JSON 导出只含布局与素材引用。大于 64 MiB 或无法解码的音频显示可定位的进度区域，不伪造波形；兼容性仍取决于媒体编码。

协议快照在 `src/contracts/`，由 Server 导出。产品需求和开发状态的版本化副本在 Server 仓库 `docs/`。

## 媒体依赖与验收

`npm ci` 安装对应平台 ffmpeg-static（b6.1.1）与共享 @zhilume/media tgz。桌面直接读取本地原文件，或下载远程素材到缓存并显示进度。输出自动同步，可重试同步而不重新编码。Web 不使用 WASM 或本地伴随服务。

```powershell
npm test
# 配套 Server 构建好后，在三个仓库并列目录下运行：
npx playwright test
```

单元测试包括真正调用捆绑 FFmpeg 的 IPC 处理/取消；浏览器测试包含裁剪、拼图、切分、上传重试、Server 音轨提取和静音视频截取。已实测 Windows EXE 的远程素材抽音轨、本机导入与直读截取；各类大文件、上限压力和其他操作系统仍需独立验收。

FFmpeg 相关分发来源与许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。


## IndexTTS 语音创作（0.11.0）

单击空音频节点打开语音编辑区；已有音频或文本通过工具栏“语音”进入。选择/上传音色参考，指定 1–30 秒片段，输入原文；参数提供语言、0.5–2 倍语速，以及按执行配置开放的情绪模式。试听播放器播放原素材，实际合成只取所选片段。关闭编辑区保留草稿，超限文字不静默截断；无在线执行器时可编辑但不能提交。

与 Server 0.9.0 / Worker 0.8.0 配套。输出新音频素材与画布节点，复用任务失败/取消/重试。真实 IndexTTS GPU 推理尚待验收，本机测试使用显式替身；没有积分、系统音色商城或自动改写朗读内容。


## H3 视频创作（0.12.0）

单击空视频节点，选择文生视频、首帧、尾帧、首尾帧或全能参考。已有素材通过工具栏视频入口进入，保留播放与拖拽。草稿离焦保存；相同输入重试不会重复提交。上传参考加入项目素材库，不额外创建节点。

Ref2VA 支持显式图片/视频/音频参考及可插入的编号标签；片段选择显示实际秒数和帧数，视频参考只提供画面，声音单独添加。参数由在线 Worker 开放，显示真实像素和 24 FPS 下的时长，默认 124 帧约 5.17 秒。关闭音频仅静音导出，不宣称省推理。无积分或假提示词优化开关。

上海二 A 已完成真实 H3 文生视频、首尾帧静音、三类组合参考、取消与后续新任务。当前样本为 512×288 / 124 帧；不代表其他尺寸、长视频、参考上限或所有 5090 部署已验收。详见配套 Server 的 H3 报告。
